# Classical complexity of the compiler

The [optimal cost formula](theorem.md) poses two classical decisions. A pair of logical Pauli representatives determines the terminal set. The hardware graph then determines how to connect those terminals at minimum cost.

## Routing for a given pair

For one terminal set $T$, check that every connected component has an even number of terminals. Within each component, form the complete graph on its terminals, weighted by shortest-path distances in the original hardware graph. Compute a minimum-weight perfect matching and lift its edges to shortest paths. Keep each hardware edge that appears an odd number of times among those paths.

This produces a $T$-join with cost at most the cost of the matching. Conversely, any $T$-join decomposes into trails pairing the terminals and possibly cycles. Replacing each trail with a shortest path and discarding cycles shows that the matching cost is at most the cost of any join. The two optima therefore agree. This is the classical reduction of minimum-cost parity correction to matching. [Edmonds and Johnson, 1973](https://doi.org/10.1007/BF01580113)

The surviving Choi generator matrix is obtained by binary elimination. Enumerating the stabilizers with $X$ on the reference and those with $Z$ on the reference, then running the matching algorithm for each pair, gives a complete exact compiler. For surviving stabilizer rank $r$, each affine set has size $2^{r-2}$ when admissible pairs exist. There are at most $4^{r-2}$ pairs, each with polynomial processing cost. A feasible pair and join give a directly checkable certificate for a claimed upper bound.

## Hardness of choosing the pair

**Proposition.** For a complete hardware graph with unit edge costs, deciding whether the minimum CNOT count at a prescribed output is at most $k$ is NP-complete. Hardness holds for CSS encodings and erasures that are correctable.

Membership in NP follows from the pair-and-join certificate. Binary syndrome decoding gives the hardness reduction. Given a binary matrix $H$, a syndrome $s$, and a nonnegative integer $k$, that problem asks whether some $x$ satisfies $Hx=s$ and $\mathrm{wt}(x)\le k$. One may take $H$ to have full row rank: eliminate redundant equations by row operations after checking consistency. An inconsistent system can be mapped to a fixed no-instance with consistent equations, for example $H=(1)$, $s=1$, and $k=0$. [Berlekamp, McEliece and van Tilborg, 1978](https://authors.library.caltech.edu/records/aw9vs-ann16)

Let $n$ be the number of columns of $H$. Use $2n+2$ visible coordinates in the order $(R, A_1,\ldots,A_n, B_1,\ldots,B_n,o)$. Put $u=\mathbf 1^{2n+2}$ and set
```math
L=\{(b,x,x,b): b\in\mathbb F_2,\ x\in\mathbb F_2^n,\ Hx=b s\}.
```
Each vector of $L$ is orthogonal to $u$. For binary $v$, denote by $X(v)$ and $Z(v)$ the Pauli strings with the indicated nonidentity supports. Consider a reduced Choi stabilizer group generated by $X(u)$ and the strings $Z(v)$ for $v\in L$.

Any admissible pair has a basis with $X$ on $R$ in the first element and $Z$ on $R$ in the second. The first must have $X$ support $u$, since $X(u)$ is the only independent $X$-type generator. The second has zero $X$ support, and its $Z$ vector is $(1,x,x,1)$ for a solution of $Hx=s$. The local anticommutation bits of this pair are exactly $(1,x,x,1)$, independent of the first element's $Z$ factors. Toggling the designated output leaves two copies of each nonzero coordinate of $x$ in the terminal set. On the complete unit-cost graph the join cost is therefore $\mathrm{wt}(x)$. Every solution gives such a pair by taking $X(u)$ and $Z(1,x,x,1)$, so the optimum equals the minimum syndrome-decoding weight.

### Realizing the reduced group by erasure

To realize this group as an actual erasure instance, let $L_0$ be the orthogonal complement of $L$ and extend $u$ to a basis $u,w_1,\ldots,w_h$ of $L_0$. Add $h$ coordinates for qubits to be erased, and define the subspace
```math
U=\mathrm{span}\{(u,0),(w_1,e_1),\ldots,(w_h,e_h)\},
```
where $e_i$ is the coordinate vector for added location $i$. The pure CSS state proportional to the uniform superposition of binary strings in $U$ has stabilizers $X(U)$ and $Z(U_0)$, where $U_0$ is the orthogonal complement of $U$.

The shortening of $U$ to vectors with zeros on the added coordinates is exactly $\mathrm{span}(u)$ on the visible locations. The shortening of $U_0$ is $L$, since a visible vector must be orthogonal to $u,w_1,\ldots,w_h$. Tracing out the added locations therefore leaves exactly the proposed reduced group.

There is no nonidentity stabilizer supported on $R$ alone in the pure state. A reference-only $X$ factor would require $e_R\in\mathrm{span}(u)$, which is impossible. A reference-only $Z$ factor would require $e_R\cdot u=0$, which is also impossible. The reference marginal is maximally mixed, and the pure state is the Choi state of a one-logical-qubit stabilizer isometry. This can be seen by fixing the two Schmidt states at $R$ as the computational basis, using the stabilizers with $X$ and $Z$ on $R$ to obtain the two encoded Pauli operators. The syndrome system has a solution because $H$ has full row rank, so the erased instance is correctable according to the [admissible-pair criterion](model.md).

All matrices and the full tableau can be constructed in polynomial time. The reduction applies to the exact physical recovery cost, although the source problem is itself a classical decoding problem. In the quantum instance the erasure pattern is fixed, no syndrome needs to be inferred, and the optimization variable is a pair of surviving logical representatives.
