# The exact CNOT cost

Use the [flagged-erasure model](model.md). For each admissible pair $P,Q$ of surviving Choi stabilizers, form its terminal set $T(P,Q;o)$ by toggling the designated output in the set of physical anticommutation sites.

**Theorem.** The minimum weighted CNOT cost of exact recovery at $o$ is
```math
C_G(o)=
\min_{P,Q\in\mathcal S_E,\ a_R(P,Q)=1}
\tau_G\!\bigl(T(P,Q;o)\bigr).
```
The minimum of an empty set is $+\infty$. When the minimum is finite, a compiler chooses a minimizing pair and join before measuring the input. Its only outcome-dependent quantum operations may be taken to be single-qubit corrections. If the output is selectable, the optimum is the minimum of $C_G(o)$ over the allowed outputs.

## From an edge set to a circuit

Choose a minimizing pair and a minimum-cost $T$-join $F$. A cycle in $F$ can be removed without changing its odd-degree vertices and without increasing its cost. Take $F$ to be a forest. Root its component containing the output at $o$, when that component has any edges, and choose an arbitrary root for each other component. Process each tree from leaves toward the root.

At a step with child $c$ and parent $p$, every unprocessed nonroot leaf has commutation bit one. To see this, the current commutation vector is the desired final vector $\mathbf e_o$ plus the odd-degree vector of the remaining forest over $\mathbb F_2$. Processing the edge to the parent should toggle the two endpoint bits, turning the child to zero. The following two cases implement that toggle with one CNOT.

1. **The parent bit is zero.** The two restrictions at the parent span a subspace of rank at most one. If the rank is one, choose a basis of the tracked pair and single-qubit Cliffords so the pair on $(c,p)$ reads $XI,ZZ$. The CNOT with control $c$ and target $p$ changes it to $XX,IZ$. The bit moves from $c$ to $p$. If the parent rank is zero, both tracked stabilizers are identity there. Reset $p$ to $|0\rangle$ and multiply the second stabilizer by the new $Z_p$ to obtain the same input pair $XI,ZZ$. Both original stabilizer equations survive the reset since they are identity there.
2. **The parent bit is one.** Choose single-qubit Cliffords so the pair on $(c,p)$ reads $XX,ZZ$. The same CNOT changes it to $XI,IZ$. Both bits become zero.

The local Clifford and pair basis choices leave all commutation bits unchanged. The pair always spans two independent reference axes. The compiler records its sign and axis conventions throughout.

At the end, the physical factors anticommute only at $o$. For each other position the factors are identities, or both are drawn from the span of a single Pauli. Measure that Pauli where needed. The outcomes set the signs of the two remaining correlations between $R$ and $o$. Their two independent Pauli axes on each side specify a maximally entangled two-qubit stabilizer state, so a single-qubit Clifford on $o$ restores $|\Phi^+\rangle$. This correction depends only on the known axes and measured signs. The recovered two-qubit marginal is pure in each branch, which establishes recovery as a channel on an arbitrary logical input. The only counted gates were the CNOTs on $F$, used once apiece.

## From any successful transcript to a join

Fix a nonzero transcript of a decoder and work backward through its operations. For a deterministic exact decoder, the average final Choi marginal is pure. Every nonzero branch must therefore have the same Bell marginal. A branch that is only required to succeed with positive probability still satisfies the argument below whenever it produces this Bell marginal.

Begin with the final $X_R X_o$ and $Z_R Z_o$ stabilizers, including identity on all other positions. At every earlier step lift these to two stabilizers of the corresponding conditional state.

- A single-qubit Clifford preserves the local commutation bit. Classical choices are fixed by the transcript.
- For measurement of a single-qubit Pauli $M$ with outcome $b$, the postmeasurement stabilizer group of a nonzero branch is generated by the premeasurement stabilizers commuting with $M$ and $bM$. In the Pauli expansion, projecting on both sides by $(I+bM)/2$ eliminates every term anticommuting with $M$ and adds the $bM$ factor to each surviving term. Write each tracked stabilizer as a premeasurement commuting stabilizer times a power of $bM$. The two premeasurement factors commute with $M$ at the measured site, as do their postmeasurement counterparts. Each pair therefore has bit zero there, with identical bits elsewhere.
- Lifting through a discard appends the identity on the discarded qubit. Lifting through a product stabilizer preparation removes the prepared qubit's factor, which belongs to a one-axis single-qubit subgroup. Both steps preserve the bits, with missing positions represented by zero. Reset is discard followed by preparation.
- A CNOT preserves the parity of the two commutation bits at its endpoints by preserving commutation of the restrictions to those two qubits. It either changes neither bit or toggles both. It has no effect on the bits at other vertices.

No operation changes the reference axes during this backward lift. The initial lifts give an admissible pair in $\mathcal S_E$ after the product ancilla factors are stripped. For each edge, retain one copy precisely when the number of CNOT uses that toggled its two bits is odd. This gives an edge set with odd-degree set $T(P,Q;o)$, since the net parity change is the difference between the initial vector and $\mathbf e_o$. Nonnegative costs make this join no more expensive than the transcript. Minimizing over pairs bounds every successful transcript from below by $C_G(o)$. The same lower bound holds if arbitrary two-qubit Clifford gates are permitted at the same edge price, since each preserves commutation on its pair of endpoints.

## Consequences

On a complete hardware graph with unit edge costs, one can pair the terminals directly. At a designated output the cost is half the smallest terminal-set size. If any surviving output location may be chosen, let $m$ be the smallest number of physical anticommutation sites of an admissible pair. Choosing one such site as output makes the cost $(m-1)/2$. Zero cost is attained precisely when there is a pair that anticommutes locally only at the output.

On a tree there is a unique edge set for a feasible terminal set. An edge belongs to the join if deletion of that edge leaves an odd number of terminals on each side. This makes routing for a fixed pair a parity calculation along the tree. On a disconnected graph, every component must contain an even number of terminals. These statements follow from summing $\mathbb F_2$ degrees over either side of the corresponding cut.
